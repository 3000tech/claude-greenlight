<objective>
Tracer: flip the render seam so a hook-written state file drives the actual overlay end to end, and tear out the shadow-mode machinery that existed only to prove it.

Purpose: FLIP-01's core act. Phase 2 built the state engine but deliberately never let it reach the UI — `select_render_sessions(legacy, shadow, False)` returned the legacy list by construction. This plan inverts that seam and proves the whole rendered path (label, status, badge inputs, display name, notifications) runs on hook-derived state with the suite green, BEFORE the broad deletions in plan 03-02 land. If the architecture is wrong, it is wrong after one commit, not after ten.

Output: `monitor.py` with a single-engine tick loop, no divergence machinery, no `state_files_mode()`, no dead `project_name()`; `test_monitor.py` realigned to the new seam.
</objective>
