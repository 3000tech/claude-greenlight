<objective>
Make the shipped architecture the documented architecture, and hand the live validation to the machine that can actually perform it.

D-12 requires the flip's live validation and every machine-side teardown step to be a user-assisted runbook, because this execution environment is code and unit tests only.

Output: a README describing what ships; a `docs/` pair holding the matrix and a recertification runbook; `03-UAT.md`; `COVERAGE.md`.
</objective>
