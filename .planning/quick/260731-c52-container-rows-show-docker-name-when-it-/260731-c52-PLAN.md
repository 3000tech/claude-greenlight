<objective>
Make two containers of the same project tell themselves apart in the overlay's Docker
section. The dev-tools launcher now names containers after the project label (`dev-tools`),
suffixing duplicates (`dev-tools-2`, `dev-tools-3`), but the overlay draws `c["project"]`
in every docker row — so two containers of one project render as two identical rows and
the user cannot tell which is which.

The fix is display-only: when the docker name starts with the project label, draw the
docker name (so the first container still reads `dev-tools` and the second reads
`dev-tools-2`); otherwise draw the project label exactly as today, which keeps containers
started before the launcher change (random names like `dreamy_bose`) readable instead of
cryptic.

Purpose: the overlay's job is to point at a specific session that needs the user. Two rows
with the same text point at nothing — the user has to guess, and guessing is what the tool
exists to remove.

Output: a pure `container_display_name()` helper next to `scan_containers()`, its single
call site in the container render loop, and Goal18 unit tests locking both branches of the
rule down without touching tkinter.
</objective>
