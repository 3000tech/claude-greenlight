<objective>
Make the monitor's saved window position survive a restart when the window is parked on a secondary display. Today `_sanitize_geometry()` measures the saved geometry's overlap against the PRIMARY screen rect only, so a window on any other monitor scores zero overlap, is judged orphaned, and is thrown back to the default bottom-right corner of the primary.

Purpose: the user confirmed the restore works on the primary and fails on every other screen. The monitor is a topmost overlay the user deliberately parks out of the way — having it jump back to the primary corner on every restart defeats the one setting it persists.

Output: a `_screen_bounds()` seam returning the virtual-screen rect (the bounding box of ALL displays) on Windows and the primary rect everywhere else, `_sanitize_geometry()` rewritten to measure overlap against it, and a test class locking both the new keep-verdicts and the unchanged reset-verdicts without tkinter or Windows.
</objective>

|----------|-------------|
| `~/.claude-monitor-config.json` (hand-editable) → `_sanitize_geometry()` | A user-editable JSON string becomes a Tk geometry; this function is the only thing standing between a bad value and an unreachable window |
