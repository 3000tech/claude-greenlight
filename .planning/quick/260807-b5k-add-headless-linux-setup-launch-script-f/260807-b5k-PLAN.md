**Paths and configuration.** Derive `REPO_ROOT` from the script's own location via `BASH_SOURCE`, never from cwd. Read the cache root from `GREENLIGHT_TK_CACHE`, defaulting to `${XDG_CACHE_HOME:-$HOME/.cache}/claude-greenlight/tk`. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deb.debian.org → local cache | Third-party binary artifacts cross the network and are later loaded into the monitor process via `LD_LIBRARY_PATH` / `PYTHONPATH` |
| local cache → python3 process | Extracted shared objects and Tcl scripts execute with the invoking user's full privileges |
| repo `.env` → this task | Live Telegram bot token and chat id sit at the repo root, gitignored; this task runs adjacent to them |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-b5k-01 | Tampering | .deb download + extraction | high | mitigate | HTTPS to the official Debian pool, exact version pins, and a sha256 allowlist verified before every `dpkg -x` — including on cached files, not just fresh downloads. Mismatch deletes the file and aborts non-zero (gate 7). |
| T-b5k-02 | Information disclosure | repo `.env` (Telegram secrets) | high | mitigate | Script never reads, copies, or references `.env`; monitor.py keeps loading it from its own `__file__` parent. Enforced by the plan prohibition and the phase-level commit gate below. |
| T-b5k-03 | Information disclosure | Telegram push fired by the verify gate | medium | mitigate | The live-launch gate runs with `HOME` pointed at an empty temp dir, so no session is scanned and no WORKING→WAITING transition can page the user's real phone. |
| T-b5k-04 | Elevation of privilege | package staging | medium | mitigate | User-space `dpkg -x` into a user-owned cache created mode 700; no root, no sudo, no apt, no system path is written. |
| T-b5k-05 | Tampering | cache directory poisoning | medium | mitigate | Default cache lives under the user's own cache dir (not a world-writable temp path) and is created 700, so another user cannot pre-seed a malicious shared object onto `LD_LIBRARY_PATH`. |
| T-b5k-06 | Denial of service | orphaned Xvfb processes | low | accept | The script reuses an existing server on the target display and starts at most one; a stray Xvfb costs a few MB and is cleaned by container teardown. |

**Package Legitimacy Gate:** not applicable. No npm/pip/cargo installs are introduced. The artifacts are official Debian binary packages fetched from `deb.debian.org` by exact version, and the ten pinned sha256 values were confirmed byte-identical to the set already proven working in this container.
